# CoStage CE

**通用实时直播 / 连麦 / 协同底座 —— 社区版 v0.2.2**

开放架构的实时直播、连麦互动与协同底座（首个场景：在线辅导课堂）。
一位房主 + 最多 4 位连麦参与者 + 不限人数观众，单机自托管。

> ⚠ **本仓库不含源代码。**
> CoStage CE 仅以编译产物形式发布（见 [Releases](../../releases)）。
> 本仓库承载文档、部署资产与项目站点。

## 一场课的形态

- **房主**开房间，分享房间号。
- **参与者**（≤4）输入 ID 进入并申请连麦；房主批准后音视频上麦。
- **观看者 / 匿名**打开房间链接即看——布局实时镜像房主端，亚秒级 WHEP 拉流，
  白板只读镜像，可发文字消息。

## 亮点（v0.2.2）

- LiveKit SFU 互动面 + ZLMediaKit WHEP 大规模分发，**零转码**
  （逐身份 WHIP 直推，H264/opus 透传）
- FloatStage 布局：可拖拽浮动连麦窗、角部吸附、互斥交换；观看者实时跟随房主布局
- 协同白板走数据面；观看者只读实时镜像
- 连麦参与者 15 秒断线保护
- 固定清晰度四档：480p30 / 720p30 / 1080p30 / 1080p60
- Web 部署管理器：安装向导、生命周期、升级、回滚——无需 systemd、无需容器运行时
- **JavaScript SDK**（发布资产 `sdk/`）：混淆单文件 `costage-sdk-<ver>.min.js` 一行 `<script>` 即得全局 `CoStageJS`，另有 ESM 版与 TypeScript 类型；第三方业务系统可零依赖嵌入直播/连麦/白板能力

## v0.2.2 修复

- **域名 + TLS 部署下媒体全黑**：管理器渲染 ZLM `[rtc] externIP` 时误把域名写进 ICE 候选（必须是 IP），
  导致转推 bot 开流失败、观看端收不到流。现取 `PublicIP`（IP 优先，其次 DNS 解析），解析不到则留空由 ZLM 自动取网卡 IP。

## v0.2.2 变更

- **许可合规补全**：随包新增 `THIRD-PARTY.md` 与 `third-party/NOTICE.livekit.txt`（Apache-2.0 §4(d) 要求复制上游 NOTICE）、
  `third-party/LICENSE.tldraw.txt`（tldraw 许可全文；其条款禁止生产环境使用，生产部署需商业许可）。

## v0.2.2 已知边界

1. **同时最多 1 个活跃房间**（服务端硬闸）：开新课须先结束当前房间
2. 无观看准入：知道房间号即可观看（签名 URL / 观看码后续版本提供）
3. 无录制回看
4. 房主白板逐人禁绘 + 一键清迹未提供
5. 付费发言（speak）功能后置
6. 单机部署假设

> 除「1 个房间 + 无录制回看」两项外，CE 与完整版功能一致；后续新增功能不再做 CE 裁剪。
